Remote Agent 网关 — Windows 登录自启动安装包（未签名）

本目录中的 install-logon-task.ps1 / uninstall-logon-task.ps1 未经 Authenticode 签名。
Windows Defender SmartScreen 或企业策略可能对未签名的 PowerShell/批处理脚本显示警告；
请仅在信任来源（本仓库 CI Artifact 或自行构建）后运行，并核对文件哈希。

默认监听 127.0.0.1:17821，不会绑定 0.0.0.0。
配对仍需在登录用户会话中手动运行 pair.bat（与 macOS 本机 npm run pair 一致）。

详细说明见仓库 docs/ops/windows-service-and-signing.md
