# Remote Agent 功能说明

> 面向使用者与验收的完整功能说明，描述**当前已落地**的产品行为。  
> 基线日期：2026-09-30  
> 规范追踪（功能 ID / 状态）见 [`functional-spec.md`](functional-spec.md)；字段与权限映射见 [`../reference/protocol-contract.md`](../reference/protocol-contract.md)。

本文只写“现在能做什么、怎么用、有什么边界”，不写规划中的能力。

## 1. 产品是什么

Remote Agent 由三部分组成：

| 组件 | 作用 |
| --- | --- |
| 手机端（Web / iOS / Android） | 配对 Mac、浏览会话、发起与继续任务、查看输出与文件 |
| macOS Agent Gateway | 认证、白名单目录校验、会话持久化、原生历史扫描、启动本机 Agent CLI |
| 本机 Agent CLI | Cursor Agent、Claude Code、Codex（由网关固定参数调用，手机不能传任意命令） |

目标用户：本机已安装至少一种受支持 Agent CLI 的单用户开发者，希望在可信手机上远程查看或启动 Mac 上的开发任务。

手机端**不持有** Agent API 密钥，也**不能**执行任意 shell。

## 2. 快速上手

1. 在 Mac 启动网关（开发：`REMOTE_AGENT_ROOTS=<白名单根目录> npm run dev`；或安装 launchd 服务）。
2. 在 Mac 运行 `npm run pair`，得到 6 位一次性配对码。
3. 手机打开应用 → 设备 → 填入网关地址与配对码。
4. 配对成功后自动同步 Cursor / Claude / Codex 会话；可筛选、按项目浏览、新建或续接。

跨设备联调时，手机无法访问 Mac 的 `127.0.0.1`，需使用受信任局域网地址或 HTTPS 反向代理。安全要求见 [`../security.md`](../security.md)。

## 3. 连接、配对与多 Mac

### 3.1 配对

- Mac 仅允许本机回环生成 6 位配对码；默认约 5 分钟过期，用一次即失效。
- 手机提交网关 URL、设备名与配对码，换取设备令牌（token）。
- 原生端令牌进系统安全存储（iOS Keychain / Android Keystore）；Web 联调版使用 `localStorage`（勿用于不可信浏览器）。

### 3.2 连接状态

- 首页标题右侧：状态灯 + 当前 Mac 名称；点击进入设备管理。
- 已连接时约每 15 秒后台同步会话、历史、配置与设备。
- 首次连接失败显示离线；已连接后的后台轮询失败**当前不会立刻**清成离线。

### 3.3 多台 Mac

- 同一手机最多保存 **8** 条 Mac 连接，记住上次使用的一台。
- 设备页可：查看名称与 origin、切换连接、添加另一台 Mac、从本机移除当前连接、撤销某设备的服务端授权。
- “从本机移除”只删手机上的凭据，不撤销 Mac 端授权；若还有其他连接会自动切到最近使用的一台。
- 撤销当前设备后，当前 token 立即失效。

## 4. 会话列表与查找

### 4.1 数据来源

列表合并两类记录：

1. **网关会话**：手机发起或续接后，由网关持久化并跑 Agent 的会话。
2. **原生历史**：Mac 上 Cursor / Claude / Codex 桌面侧已有会话的摘要。

同一原生会话若已有对应网关会话（按 `agent:nativeId`），只显示网关侧；并再按 `source + agent + id` 去重。

### 4.2 最近 / 项目视图

- **最近**：按更新时间，最多展示 **20** 条（不会因单个高频项目挤掉其他项目）。
- **项目**：按 Git 根目录（找不到则用规范化 cwd）分组；同名不同路径保持独立，必要时用父路径消歧显示名。每个 Agent Tab 下单项目最多 **20** 条；项目可折叠，折叠状态按网关 URL 记忆。项目行可一键「新会话」，预填该项目最近 cwd。

### 4.3 Agent 筛选与搜索

- Tab：全部 / Cursor / Claude / Codex。
- Cursor / Claude / Codex Tab 第二行显示**额度摘要**（见第 7 节）；不显示历史总数。
- 统计行：当前筛选内「进行中」与「已完成 · 未读」；右侧为「新会话」（已连接时始终可用）。
- 本地搜索标题、项目名、分支/权限标签、Agent 名；不向网关发搜索请求。

### 4.4 列表行展示

- 显示：标题、项目、相对更新时间。
- 运行中：旋转图标。
- 完成且未读：蓝点；打开详情后清除。已读完成不显示“已完成/未读”文字。
- 列表**不再**单独展示“原生历史 / 只读记录”标签行。

### 4.5 缓存与同步提示

- 同一网关 URL 重连时，可先展示最多 **200** 条上次摘要并提示“正在同步”，再换成最新数据。
- 缓存不含 token、cwd、消息正文或事件；不同 Mac 的缓存互不复用。
- 同步失败可保留缓存并点「重试」。

## 5. 新建会话

入口：统计行右侧「新会话」，或项目分组旁的「+」。

表单字段：

| 字段 | 说明 |
| --- | --- |
| 任务指令 | 必填；会作为会话标题来源（过长截断） |
| 项目 | 可选下拉，来自已同步会话的项目（按 `projectId` 去重）；选中后写入对应工作目录 |
| Mac 工作目录 | 绝对路径；须存在且落在网关 `REMOTE_AGENT_ROOTS` 白名单内 |
| Agent | Cursor / Claude / Codex |
| 权限 | 见下一节 |

提交后：网关创建会话并启动固定 adapter；手机进入全屏详情并增量拉取输出。

## 6. 权限模式

协议值：`plan` | `ask` | `auto` | `full`。新建会话 UI 提供三选一（默认跟随设置「默认受限执行」）：

| UI 文案 | 协议值 | 实际效果（摘要） |
| --- | --- | --- |
| 受限执行 | `ask`（与 `plan` 同类） | 规划/只读类；**不是**手机逐项审批 |
| 自动执行 | `auto` | 白名单 cwd 内可写；Cursor 为 Smart Auto（`--auto-review`） |
| 完全允许 | `full` | Cursor `--force`；Claude `bypassPermissions`；Codex `danger-full-access` |

共同边界：

- 无论何种权限，**工作目录仍必须通过白名单**；客户端不能改 CLI 可执行文件或任意参数。
- 设置页「默认受限执行」仅影响新建/原生续接的默认值，当前**不持久化**（刷新/重启后恢复默认开启）。

## 7. Agent 额度

已连接时约每 **60** 秒刷新一次 `/v1/agents/usage`，展示在 Agent Tab 第二行：

| Agent | 可用时 | 特殊态 |
| --- | --- | --- |
| Cursor | Dashboard 本月 included 剩余比例 | 无套餐窗口或失败 →「无法获取」 |
| Claude | 订阅窗口剩余比例 | API Key / 无法探测 →「API模式」或「无法获取」 |
| Codex | ChatGPT 登录下 5 小时/周等窗口剩余 | API Key 登录 →「API模式」 |

额度失败不得阻塞会话同步；响应不得带回账号、密钥或上游原始正文。

## 8. 会话详情

### 8.1 布局与交互

- 标题栏避开系统状态栏；副标题含 Agent、项目、可选分支/权限标签、状态与相对时间。
- 活动任务约每 **1** 秒增量拉取：网关会话读事件；原生 Codex 读 snapshot 消息。终态再同步一次后停止。
- 用户/助手正文：安全 Markdown（含 GFM）；不执行原始 HTML。支持 Mermaid（失败时回退源码）。
- 用户问题滚过原位置后吸顶；超两行默认折叠；多轮问题切换有覆盖动画（系统“减少动态效果”时关闭）。
- 用户上翻查看旧内容时，新输出不强行拉回底部。
- 工具调用、审批等待、错误单独展示；CLI `stderr` 合并为默认折叠的「Agent 诊断日志」。

### 8.2 继续对话

- **网关会话**：已完成/失败且有 `nativeId` 时可继续；沿用原 cwd 与权限（设置页影响原生续接默认权限）。
- **原生历史**：Claude、Codex、新版 Cursor Glass/composer（白名单内）可续接；续接会新建一条网关会话承载事件。
- **仅查看**：白名单外 cwd、旧 Cursor `acp-sessions`、或不可续接记录；底部输入框显示「仅查看」并禁用。
- 运行中不可并发续接。手机端**尚无**取消运行中会话的按钮（网关 API 已支持取消）。

### 8.3 本机文件预览

正文中的相对路径、绝对路径、`file://` 链接经网关受控读取：

- 必须以会话 cwd 为根做 realpath 校验；拒绝目录、符号链接逃逸、缺失文件、超过 **20 MiB**。
- 图片可内联与全屏；PDF/文本应用内预览；其他类型可下载/分享。
- `http(s)`、锚点、邮件链接仍按外部链接处理。

## 9. 原生历史来源（Mac 侧）

| Agent | 摘要来源 | 消息正文 | 续接 |
| --- | --- | --- | --- |
| Cursor | 优先 IDE `composerHeaders`（与侧栏标题/归档一致）；缺库回退 chats/acp | `~/.cursor/projects/*/agent-transcripts` 用户/助手文本 | Glass/composer 默认可续接；旧 acp 与白名单外只读 |
| Claude | `~/.claude/projects` 等本机历史 | 用户/助手文本（清洗注入、截断过长） | 白名单内可续接 |
| Codex | 官方 app-server `thread/list`（**不含 archived**）；失败回退 JSONL | 用户/助手文本 | 白名单内可续接；运行中原生会话拒绝并发续接 |

所有 cwd 的历史标题均可见；白名单外标记为不可续接（只读）。

## 10. 设置

| 项 | 行为 |
| --- | --- |
| 默认受限执行 | 默认开；影响新建与原生续接默认权限；不持久化 |
| Agent 状态通知 | UI 可开关，**无**系统推送实现（占位） |

底部导航：会话 / 设备 / 设置。

## 11. Android / iOS 运行时要点

- Capacitor 壳 + 深色适配系统栏；安全区、键盘避让、BottomSheet、滚动手势遵循移动端 runtime 约定。
- Android 系统返回：依次关闭键盘 → sheet → 会话详情/搜索；首页最小化应用。
- iPad 大屏使用居中可读工作区（约 760pt）。
- 更新手机端代码需重新 `build` + `cap sync` + 安装 APK/IPA；应用内下拉不能更新前端包。

## 12. Mac 网关与运维

- 默认端口 `17821`；开发可绑定 `0.0.0.0` 供局域网访问（仅受信任网络）。
- `REMOTE_AGENT_ROOTS`：新建/续接/读文件的真实路径白名单（macOS 用 `:` 分隔）。
- 可选 launchd 用户服务：`service:install` / `status` / `uninstall`；卸载保留 SQLite 与日志。
- 项目若在 Desktop/Documents/Downloads，可能需给 Node「完全磁盘访问权限」。

主要 HTTP 能力（均需设备 Bearer，除健康检查与配对）：健康检查、配对、设备列表与撤销、Agent 检测与额度、配置（hostname/roots）、会话 CRUD/继续/取消/事件、原生历史列表/消息/续接/文件读取、SSE（手机暂未消费）。

## 13. 当前明确不做 / 受限

以下**不是**完整已交付能力：

- 手机逐项批准/拒绝工具调用（仅展示“等待 Mac 端确认”）。
- 系统推送（APNs/FCM）、锁屏隐私策略。
- 多用户账号、云端中继、任意终端/任意 CLI 参数。
- 公网开箱部署、应用商店正式签名与生产密钥轮换。
- Cursor 旧 acp/chats store 的消息正文（agent-transcripts 已可读）。
- 移动端消费 SSE（详情仍轮询）。
- 移动端根据 `/v1/agents` 禁用未安装 Agent。
- 取消运行中会话的手机入口；取消态在列表中仍显示为“已完成”。
